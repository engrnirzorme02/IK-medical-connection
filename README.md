# IK Medical Connection — Production Medical MCP Server

AI-driven Clinical Decision Support System & Medical MCP Server for Dr. Assistant workflows.
Integrated with:
- **openFDA API**: Drug adverse events (FAERS), boxed warnings, contraindications, recalls.
- **RxNorm / DailyMed**: Clinical drug normalization (RxCUI) and drug-drug interaction (DDI) analysis.
- **PubMed (NCBI E-utilities)**: Biomedical literature and clinical trial research.
- **Clinical Lab Report Analyzer**: Reference range evaluation and critical anomaly detection.
